# react-zpl-cli

Live preview (`react-zpl dev`) and export (`react-zpl export`) for [react-zpl](../react-zpl) labels.

```sh
npx react-zpl dev [--dir labels] [--port 3000]
npx react-zpl export [--dir labels] [--out out] [--dpi 203] [--margin 1mm] [--svg] [--template]
```

See the [react-zpl README](../react-zpl#preview-while-you-design) for what the viewer does.
